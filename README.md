# 모델하우스 플래너

아파트 평면도 위에 가구를 배치하고, 비내력벽 철거를 표시하고, 치수를 재 보는 인테리어 설계 도구입니다. 버튼 하나로 Three.js 3D 공간으로 넘어가 위에서 내려다보거나 사람 눈높이로 걸어 다닐 수 있습니다. 한국어가 기본이고 영어로 전환할 수 있습니다.

> 현재 평면은 임시 평면입니다. 한국 아파트 84㎡(A·B 타입)·59㎡ 평면과 타입 선택 기능은 다음 단계에서 추가합니다.

## 기능

**2D 평면 배치**
- 1:50 / 1:100 축척 보기, 단위 mm
- 왼쪽 가구 목록에서 60여 종의 가구·가전을 끌어 놓기 (침실, 거실, 주방·식당, 욕실, 가전, 서재·취미)
- 끌어서 이동, 회전(Shift: 자유 각도), 크기 조절, 벽에 자동으로 붙이기
- 거리 측정 (벽에 자동으로 붙음, Shift로 수평·수직 고정)
- 비내력벽 철거 표시, 내력벽 별도 표시
- 레이어 켜고 끄기: 치수, 방 이름, 가구, 격자, 내력벽

**3D 공간**
- 조감·사선·탑뷰, 방 목록을 누르면 그 방으로 카메라 이동
- 걸어보기: 데스크톱은 WASD + 마우스, 터치 기기는 가상 조이스틱, 문을 눌러 열고 닫기
- 전체 벽 / 단면 벽 전환, 일조 시간 슬라이더, 야경 조명
- 문짝 틈과 손잡이, 패브릭 헤드보드, 금속·도기 반사 재질 등 세밀한 가구 모델
- 3D에서도 가구를 선택해 끌 수 있고 2D와 실시간으로 연동

**도면 정보와 견적**
- 방별 면적과 실사용 면적 합계 자동 계산
- 방마다 바닥재 변경 (강마루, 강화마루, 원목마루, 포세린 타일, 타일, 논슬립 타일, 장판, 대리석), 면적 + 로스 5%로 원화(₩) 견적
  - 단가는 자재+시공 참고가이며 실제 견적과 다를 수 있습니다 (`src/data/materials.ts`)
- 실행 취소 / 다시 실행, 도면은 브라우저에 자동 저장
- 한국어 / English 전환 (상단 오른쪽 버튼, 선택을 기억)
- PNG 이미지 저장, 도면 JSON 내보내기 / 불러오기 (불러올 때 형식 검증)

## 시작하기

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev          # 개발 서버 (http://localhost:5173)
```

빌드:

```bash
npm run build        # dist/ — 정적 호스팅용. 3D 엔진은 처음 3D로 전환할 때 별도 파일로 로드
npm run preview      # dist/ 미리 보기
npm run build:single # dist-single/index.html 한 파일 — 서버 없이 더블클릭으로 열기용 (시스템 한글 폰트 사용)
npm run typecheck    # 타입 검사
```

## 단축키

| 키 | 동작 |
| --- | --- |
| `T` | 2D / 3D 전환 |
| `V` / `M` / `X` | 선택 / 측정 / 벽 철거 |
| `R` / `Shift+R` | 선택한 가구 시계 / 반시계 방향 90° 회전 |
| `Delete` / `Backspace` | 선택한 가구 삭제 |
| `Ctrl/⌘ + D` | 선택한 가구 복제 |
| `Ctrl/⌘ + Z`, `Ctrl/⌘ + Shift + Z` | 실행 취소, 다시 실행 |
| 방향키 (`Shift`) | 선택한 가구 10mm (100mm) 이동 |
| `F` | 화면에 맞춤 |
| `+` / `-` | 확대 / 축소 |
| `[` / `]` | 왼쪽 가구 목록 / 오른쪽 속성 패널 접기·펼치기 |
| `Shift + F` | 전체 화면 |
| `Esc` | 현재 동작 취소 |
| 걸어보기: `WASD` / 방향키, `Shift`, `E` | 이동, 빠르게 걷기, 문 열고 닫기 |

## 구조

Vite + TypeScript, UI 프레임워크 없이 DOM을 직접 다룹니다. 2D 평면도는 SVG, 3D는 [Three.js](https://threejs.org/) r160입니다.

```
src/
  main.ts          시작점: 렌더링 연결, 이벤트 바인딩
  core/            상태·실행 취소·저장(state), 편집 동작(actions), 기하 계산, 이름 표시
  data/            평면(plan), 바닥재와 단가(materials), 가구 목록(library)
  i18n/            한국어(ko)·영어(en) 사전 — 키를 추가하면 두 사전에 모두 있어야 타입 검사 통과
  plan2d/          SVG 평면도 그리기, 확대·이동, 벽 붙이기, 포인터 조작
  ui/              툴바, 오른쪽 패널, 가구 목록, 키보드, 가져오기·내보내기, 2D/3D 전환
  view3d/          3D 장면(index), 가구 모델(furniture), 기본 도형(prims), 재질(materials)
```

도면 데이터는 브라우저 `localStorage`(`floorplan-kr:plan-v2`)에 저장됩니다.

## 평면 바꾸기

평면 데이터는 `src/data/plan.ts`에 있습니다.

- `ROOMS`: 방 다각형과 기본 바닥재 (방 이름은 `src/i18n`의 `room.*` 키)
- `WALLS` / `WINS` / `DOORS` / `SLIDES`: 벽(내력벽·외벽·비내력벽·낮은 벽), 창, 여닫이문, 미닫이문
- `MATS`(`src/data/materials.ts`): 바닥재 단가
- `LIB`(`src/data/library.ts`): 가구 목록 (종류, 이름 키, 기본 크기, 색)
- `buildFurniture()`(`src/view3d/furniture.ts`): 가구 종류별 3D 모델
